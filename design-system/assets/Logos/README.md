# Logo

Het aangeleverde VELORIQ-logo, geknipt uit de banner (PNG, lichte grond). Een V in diep teal (#162a28) met een sprintende wielrenner, een gouden baan met drie waypoints (#b58e5c), het woordmerk VELORIQ in geometrische kapitalen met een gouden Q, en de tagline "AI Coaching met persoonlijke benadering."

| Bestand | Wat | Gebruik |
| --- | --- | --- |
| `veloriq-lockup-light.png` | beeldmerk + woordmerk + tagline | homepage-hero, auth-scherm (linkerpaneel op licht), e-mail |
| `veloriq-mark-light.png` | alleen het beeldmerk | app-icoon, favicon-basis, avatar van het merk |
| `veloriq-wordmark-light.png` | alleen VELORIQ | navigatiebalk op licht, footer |
| `veloriq-logo-dark-sketch.png` | de donkere schets (met gloed, onscherp) | alleen als referentie voor de donkere versie; niet in de UI gebruiken |

Regels:

- Alleen op lichte grond (`bg` ivoor, `surface` wit); de PNG heeft een witte achtergrond. Op donkere grond zet je het woordmerk in tekst: `text`, kapitalen, tracking .18em, de Q in `accent` — tot er een vectorversie (SVG) met transparante achtergrond is. Vraag die bij de ontwerper; een PNG uitknippen levert halo's op.
- Minimale breedte lockup 200px, woordmerk 120px; beeldmerk los vanaf 32px. Vrije ruimte = de hoogte van de V-poot.
- Nooit vervormen, hertekenen of in ijs-teal/brons zetten. De gouden waypoint-baan is de bron van de koerslijn in de UI; gebruik die vorm, niet het beeldmerk zelf, als decoratie.
