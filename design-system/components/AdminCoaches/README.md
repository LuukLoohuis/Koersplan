Admin · Coaches: klein beheerscherm om coaches uit te nodigen, goed te keuren en te pauzeren.

- Kop met telling (actief · wacht op goedkeuring · gepauzeerd) en "Coach uitnodigen" (primair).
- DataTable: coach met e-mail, woonplaats, status (`chip-good` Actief, `chip-warn` Wacht op goedkeuring met rij op `warn-soft`, neutraal Gepauzeerd met rij op 70%), atleten als balk + "12 / 15", beschikbaarheid, sinds, en acties per rij (Pauzeren / Goedkeuren + Afwijzen / Hervatten).
- Onder de tabel: uitnodiging per e-mail en totalen (atleten bij een coach, vrije plekken).
- Alleen voor de rol admin; geen grafieken, geen koers-taal.
